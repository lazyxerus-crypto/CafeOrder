# 판매처 아이콘

사용자 제공 PNG만 사용한다. 다운로드한 이미지나 임시 글자 아이콘은 사용하지 않는다.

| 파일 | 판매처 | 제공된 원본 파일명 |
|---|---|---|
| mega.png | 메가커피 | www.megaco__ee.co.kr_32x32.png |
| piece.png | 파미유 / PieceCake | www.piececake.co.kr_32x32.png |
| food.png | 푸드레인 | oodrain.com_32x32.png |
| wym.png | 우양 | www.wym.co.kr_32x32.png |
| nuldam.png | 늘담 | nuldampartners.com_32x32.png |
| coupang.png | 쿠팡 | www.coupang.com_32x32.png |
| naver.png | 네이버 스마트스토어 | www.naver.com_32x32.png |

교체 시 해당 파일명으로 저장하고 다시 빌드/실행한다. 빌드/게시 폴더의 Assets/Sellers에 복사된다. 원본 비율을 유지하는 Zoom과 고정 크기 슬롯을 사용하며, 앱 실행 동안 모든 화면이 동일한 이미지 캐시를 공유한다. 파일 누락/손상은 해당 판매처의 기본 상점 placeholder로 처리한다. 아이콘 파일명은 상품 URL 지원 여부를 추가로 확정하는 근거가 아니다.
