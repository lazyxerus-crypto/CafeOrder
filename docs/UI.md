# 화면 기준 (구현 전)

메인 탭은 정확히 `상품`, `주문기록`, `사이트관리`, `상품추가`, `로그`, `설정` 6개다. 별도 로그인 탭은 없다.

50대 사용자를 기준으로 큰 글씨, 큰 버튼, 단순한 화면, 텍스트 + 아이콘, 낮은 인지 부담을 우선한다. 최소 1280×720 및 Windows 배율 100%/125%/150%를 고려한다. 불필요한 애니메이션은 금지한다.

## 상품과 장바구니

상품 화면 오른쪽에 통합 장바구니를 배치한다. 일반 장바구니는 공급처별로 묶는다. AUTO 공급처 카드에는 개별 `[주문하기]`, 화면 아래에는 큰 `[전체 주문하기]`를 둔다.

전체 주문은 별도 진행창에서 위에서 아래로 카드 하나씩 진행한다. 각 카드에 개별 주문 기능을 둔다. ▲▼, drag & drop, 사용자 지정 주문순서는 만들지 않는다. 카드 구성/완료 처리/상태는 [ORDER_FLOW](ORDER_FLOW.md), 쿠팡/네이버 표시 및 버튼은 [수동 주문 규칙](suppliers/COUPANG_NAVER.md)을 따른다.

## 카테고리와 정렬

카테고리 목록은 다음으로 고정한다.

`전체`, `원두`, `일회용품`, `유제품`, `파우더`, `베이스/농축액`, `시럽/소스`, `과일`, `티백`, `청`, `디저트/스낵`, `기타`

`전체`는 필터용이며 실제 저장 카테고리가 아니다. 기본 정렬은 카테고리 → 상품명이다. 선택 정렬은 `기본순`, `이름순`, `가격순`, `자주주문한순`이다. 자주주문한순은 나중에 실제 주문기록으로 계산하며 검색 클릭 횟수나 사용자 선택 학습을 쓰지 않는다.
