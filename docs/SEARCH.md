# 로컬 상품 검색

검색 대상은 SQLite에 저장된 활성 상품이다. 검색 중에는 웹사이트나 외부 API를 호출하지 않고 메모리의 상품명만 읽는다. 결과는 직접 일치 → 오타·표기·동의어 확장 일치 → OR 기반 관련·부분 일치 순으로 정렬한다. 3순위에서는 핵심 단어·희소성·공통 문자열 길이·브랜드·규격을 함께 평가한다. ProductId 중복만 제거하고 결과 개수는 제한하지 않는다. 같은 입력과 데이터에는 같은 순서를 사용한다.

카페 상품명 사전은 초코/초콜릿/코코렛, 파우더/분말/가루, 뚜껑/리드/lid, 토피넛/피넛/땅콩, 홍차/블랙티/얼그레이, 냉동과일, 연유/응오이사오, 커피봉투/테이크아웃 봉투 등을 연결한다. 흔한 오타는 사전과 제한된 글자 거리로 찾는다. 수량·규격은 1kg/1000g, 1L/1000ml, 온스/oz, 같은 숫자의 파이/mm 등을 비교하며 다른 값은 동일 규격으로 취급하지 않는다. 증정품 문구만 일치하면 주상품보다 낮게 평가한다. 상품 원문과 가격·옵션은 변경하지 않는다.

상품 등록·이름/URL 변경·삭제/복원·XLSX 가져오기 후 검색 결과를 다시 계산한다. 카테고리·판매처 필터는 유지한다. Google 검색 API, 상시 AI/LLM, embedding, 유료 API, 클릭 학습, 검색 이력 저장은 사용하지 않는다.
