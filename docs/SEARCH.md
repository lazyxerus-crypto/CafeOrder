# 로컬 검색 기준

검색 대상은 CafeOrder에 등록된 로컬 상품뿐이다. 고정된 알고리즘과 사전을 사용한다.

금지: Google 검색 API, 항상 실행되는 AI/LLM, embedding 검색, 사용자 검색 행동 학습, 상품 클릭 학습, query → product 선택 이력 저장.

상품명을 세부 DB 필드로 쪼개지 않고 검색 시 문자열을 정규화한다. 사전/정규화 예:

- 뚜껑 = 리드 = lid
- 빨대 = 스트로우 = straw
- 20oz = 20온스 = 20온즈
- 컵/뚜껑 문맥에서 98파이와 98mm를 연결할 수 있음

문맥 조건을 무시해 모든 상품에 치수 동치를 적용하지 않는다. 상품 원문 저장은 [DATABASE](DATABASE.md), 정렬 기준은 [UI](UI.md)를 따른다. 이번 단계에는 검색 코드를 구현하지 않는다.
