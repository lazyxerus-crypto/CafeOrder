# MegaCoffee

- 유형: AUTO.
- 무료배송 초기 설정값: 50,000원.
- 주문/로그인/무료배송 공통 규칙: [ORDER_FLOW](../ORDER_FLOW.md).
- 로그인 1단계: 공식 홈 `https://www.megacoffee.co.kr/`에 설치된 Edge로 접속한다. `a[href*='logout.php']`가 있으면 로그인 완료, `#formLogin #loginId` 또는 로그인 링크가 있으면 로그인 필요로 판별한다. 둘 다 확인할 수 없으면 사용자 확인 대기이며 URL만으로 성공을 추정하지 않는다.
- 상품조회: 로그인된 메가커피 전용 프로필로 사용자가 입력한 `goods_view.php?goodsNo=` URL 한 건을 읽는다. 페이지 상품코드·상품명·판매가·구매 버튼 상태·이미지가 확인된 경우에만 Draft에 반영하고, 이미지는 로컬 WebP로 저장한다. 실패하면 Draft와 URL을 유지한다.
- XLSX의 URL만 있는 신규 행도 같은 조회를 행별로 순차 실행한다. 판매처+`goodsNo`가 기존 DB 또는 파일 앞 유효 행과 같으면 조회 전에 건너뛰고, DB 중복은 기존 ProductId를 알린다. 기존 ID 행의 다른 신규 상품 URL은 기존 상품을 바꾸지 않고 새 ID로 등록한다. 추적 파라미터를 제거한 공식 URL로 조회하며 로그인 만료·조회 실패는 전체 반영을 중단한다.
- 실제 URL 상품을 카드에서 담으면 로컬 수량을 즉시 바꾼다. 마지막 성공 조회 시각이 24시간 미만이면 저장값을 쓰고, 없거나 오래됐으면 해당 상품만 비동기 조회한다. 조회 중 재클릭은 추가 조회를 만들지 않고 +/-는 항상 로컬 수량만 바꾼다. 성공하면 SQLite 상품/장바구니의 가격·이미지·품절·UTC 성공 시각을 갱신하고, 실패하면 기존 저장값을 유지한다. 사용자 로그아웃/세션 만료 시 로그인 필요 상태로 바꾸며 자동 재로그인은 하지 않는다.
- 주문 진행창의 [주문 시작]/[전체 주문 시작]에서만 주문 대상 스냅샷을 DB에 저장한 다음 사이트 장바구니에 접근한다. `goodsNo`와 수량을 읽어 기존 내용이 다르면 사용자 확인 후 구성한다. 상품 페이지 품절/옵션/가격을 확인하고 사이트 장바구니를 다시 읽어 상품 코드·옵션·수량이 모두 일치하면 `READY`로 남긴다. 비우기 버튼의 정확한 `confirm`만 승인하고 숨겨진 프레임 응답 뒤 실제 장바구니를 재확인한다. 불명확한 클릭은 반복하지 않는다. 사이트 장바구니 준비는 주문 완료가 아니며 최종 주문/결제 버튼은 누르지 않는다.
