# Coupang / Naver SmartStore

유형: MANUAL_BROWSER. 통합 장바구니에 포함하며 일반 화면에서는 공급처별로 묶어도 된다. 실제 주문 진행 단위는 기본적으로 상품 URL 하나당 카드 하나다.

## 사용자가 직접 주문

CafeOrder는 `[사이트에서 주문하기]`로 상품 URL을 열어준다. 수량과 옵션은 실제 사이트에서 사용자가 직접 처리한다. CafeOrder에 `1개`를 실제 주문수량처럼 표시하지 않는다.

자동 로그인, 상품 수량 변경, 옵션 선택, 장바구니 조작, 결제, CAPTCHA/anti-bot 우회, OTP 입력, 결제 비밀번호 입력을 자동화하지 않는다.

구매 후 사용자가 `[주문완료로 기록]`을 누르면 해당 상품 주문만 완료 처리한다. 실제 주문번호와 최종 금액 입력은 선택사항이며 없는 값을 임의로 만들지 않는다. 해당 주문의 카드/장바구니 제거는 [ORDER_FLOW](../ORDER_FLOW.md)를 따른다.

CafeOrder의 자동 무료배송 조건을 적용하지 않는다. AUTO 원격 장바구니 재구성 및 로그인 유지 자동화 흐름을 적용하지 않는다.
