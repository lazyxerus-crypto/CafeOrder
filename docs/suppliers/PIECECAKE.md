# PieceCake / 파미유

- 유형: AUTO.
- 무료배송 초기 설정값: 99,000원.
- 주문/로그인/무료배송 공통 규칙: [ORDER_FLOW](../ORDER_FLOW.md).
- 홈페이지: <https://www.piececake.co.kr/>. 상품 코드는 `prodNo` (`PD` + 숫자)로 식별한다.
- 판매처 전용 Edge 프로필에서 직접 로그인하고, 보이는 로그아웃·정보수정 링크로 세션을 확인한다. 재실행 후 세션 재사용을 확인했다.
- 로그인된 상품 페이지에서 상품명·판매가·박스 구매 단위·이미지·품절 상태를 읽는다. 판매 단위는 상품명에 한 번만 붙이고 표시가격은 금액과 `원`만 쓴다. `PD2637`의 이름·가격·이미지·구매 단위를 실제 페이지와 대조했다.
- 상품 URL 등록과 URL 전용 XLSX 가져오기는 실제 조회 결과를 SQLite에 저장한다. 동일 `prodNo`는 추적 파라미터가 달라도 중복으로 본다.
- 사이트 주문목록은 실제 응답이 정상인 `/affiliate/prdorder`를 사용한다. `/affiliate/prorder`는 2026-09-24 읽기 검사에서 HTTP 500이었다.
- 주문 시작 후 SQLite 대상 스냅샷을 저장하고 기존 사이트 항목을 상품별 X와 확인창으로 제거한다. 빈 목록을 확인한 뒤 상품을 담고 `prodNo`·BOX 단위·주문 수량·상품 단가를 다시 읽어 `READY`만 기록한다. 실사이트 검사에서 PD2637 BOX 2개가 일치했다. 최종 주문·결제는 실행하지 않는다.
