# Nuldam Partners / 널담

- 유형: AUTO.
- 무료배송 초기 설정값: 100,000원.
- 주문/로그인/무료배송 공통 규칙: [ORDER_FLOW](../ORDER_FLOW.md).
- 실제 홈: `https://nuldampartners.com/`; 장바구니: `https://nuldampartners.com/order/basket.html`.
- 독립 Edge 프로필의 로그인은 화면의 로그아웃·정보수정 링크로 확인한다. 쿠키 보관은 Windows 사용자 범위 암호화를 사용한다.
- 실제 상품 `product_no=250`에서 `(널담)뚱낭시에-솔티드바닐라(15개입)`, `24,000원`, 이미지와 재고 상태를 확인했다. `15개입`은 한 주문 단위의 구성 수량이며 장바구니 수량은 구매 단위 개수다. 상품 중복 기준은 판매처+`product_no`이고 `cate_no`·`display_group`은 무시한다.
- URL 등록·XLSX 링크 행·24시간 경과 후 최초 담기 조회를 지원한다. 원격 장바구니 쓰기는 `[주문 시작]`과 SQLite 주문 대상 스냅샷 저장 뒤에만 실행한다. 사이트의 비우기 확인창을 검증하고 빈 상태를 확인한 뒤 `ADD TO CART`·`장바구니 이동`을 사용해 코드·구성·수량·단가를 다시 읽는다. `바로 구매하기`와 최종 주문·결제는 실행하지 않는다.
